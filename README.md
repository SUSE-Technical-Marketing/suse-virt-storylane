# SUSE Virtualization — Storylane Demo Hub

Static site and PPTX deck for the SUSE Virtualization interactive demo series.

## Contents

- `index.html` — Demo hub landing page (SUSE-branded)
- `schedule.html` — 5-day recording and delivery schedule
- `css/style.css` — Shared styles
- `docs/suse-virt-0-to-hero.md` — Full lab guide with Storylane recording scripts
- `docs/suse-virt-storylane-deck.pptx` — Sales deck (13 slides, dark SUSE theme)

## Audience

Sales Engineers and prospects. Six interactive Storylane demos covering SUSE Virtualization from first login to a running Kubernetes cluster on HCI.
