The platform

What is SUSE Virtualization?

Open-source HCI built on Kubernetes. Not bolted onto it.

01
KubeVirt on SLE Micro

VMs run as Kubernetes workloads on Elemental for SLE Micro 6.1 — an immutable OS that removes routine maintenance. Manage VMs with kubectl, YAML, or GitOps.

02
Longhorn

Distributed block storage, built in. No external SAN needed. 3-replica replication across nodes by default. VM snapshots stored locally; backups offloaded to NFS or S3.

03
SDN Networking

Canal handles internal cluster traffic. Multus + bridge CNI delivers L2 VLAN networks to VMs. Kube-OVN manages IP pools for LoadBalancer services. No NSX required.

04
Rancher Prime

Single pane of glass for Harvester and all guest Kubernetes clusters. Built-in Prometheus and Grafana observability. Multi-tenant RBAC across clusters and projects.

Before you deploy

Hardware and software requirements

Minimum specs for a 3-node proof-of-concept cluster. Production thresholds are higher — use these as a starting point for sizing.

🖥
CPU
8-core min / 16-core production

x86_64 and ARM64 supported. Hardware-assisted virtualization required.

🧠
Memory
32 GB min / 64 GB production

Per node. First 3 nodes become HA management nodes automatically.

💾
Storage
250 GB min / 500 GB production

SSD or NVMe required — 5,000+ random IOPS per disk. Separate OS and data disks recommended.

🌐
Network
1 Gbps min / 10 Gbps production

2 NICs recommended per node — one for management, one for VM workload traffic. Switch must support VLAN trunking.

⎈
Cluster size
3 nodes minimum

Required for HA management plane and live migration. The first 3 nodes auto-promote to management nodes.

📦
Software
SUSE Virtualization v1.7.1

Rancher Prime v2.13.1 or later for multi-cluster management. ISO installer for bare-metal, USB, or PXE boot.
