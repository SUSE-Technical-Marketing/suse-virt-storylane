The platform

What is SUSE Virtualization?

Open-source HCI built on Kubernetes. Not bolted onto it.

01
KubeVirt on SLE Micro

VMs run as Kubernetes workloads on Elemental for SLE Micro 6.1 — an immutable OS that removes routine maintenance. Manage VMs with kubectl, YAML, or GitOps.

02
Longhorn

Distributed block storage, built in. No external SAN needed. 3-replica replication across nodes by default. VM snapshots stored locally; backups offloaded to NFS or S3.

03
SDN Networking

Canal handles internal cluster traffic. Multus + bridge CNI delivers L2 VLAN networks to VMs. Kube-OVN manages IP pools for LoadBalancer services. No NSX required.

04
Rancher Prime

Single pane of glass for Harvester and all guest Kubernetes clusters. Built-in Prometheus and Grafana observability. Multi-tenant RBAC across clusters and projects.

No proprietary hardware

Runs on the servers you already have

SUSE Virtualization installs on standard x86_64 or ARM64 bare metal. No certified-only hardware, no storage appliances, no special networking gear.

🖥
Architecture
x86_64 and ARM64

Any server with hardware-assisted virtualization. Works on Dell, HPE, Lenovo, Supermicro, Arm-based servers, and more.

💾
Storage
No SAN required

Longhorn turns local SSD or NVMe disks into replicated distributed storage. No external storage array needed.

🌐
Networking
Standard switches

VLAN trunking on your existing switches is all you need. No proprietary SDN hardware, no NSX license.

⎈
High availability
3-node minimum

First 3 nodes auto-promote to HA management nodes. Add more nodes at any time to expand capacity.

📦
Installation
ISO, USB, or PXE

Boot from the Harvester ISO, a USB stick, or PXE-boot across your rack. Air-gapped deployment fully supported.

🔓
License
100% open source

Apache 2.0 licensed. No per-VM fees, no CPU socket taxes, no proprietary add-ons to unlock basic features.
