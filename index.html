The problem

Why teams are rethinking their virtualization stack

Legacy hypervisors were built for a world that no longer exists.

💸
Licensing costs

VMware bills jumped 2–5x post-Broadcom. Customers need a credible exit path before the next renewal.

🏗
Operational silos

VMs and Kubernetes managed with different tools, different skills, different teams. Two ops models for one platform.

🔒
Vendor lock-in

Proprietary storage, networking, and APIs at every layer. Moving anything means rebuilding everything.

SUSE Virtualization solves all three. One platform. 100% open source.

The platform

What is SUSE Virtualization?

Open-source HCI built on Kubernetes. Not bolted onto it.

01
KubeVirt

VMs run as Kubernetes workloads. Manage virtual machines the same way you manage containers — kubectl, YAML, GitOps if you want it.

02
Longhorn

Distributed block storage, built in. No external SAN needed. 3-replica replication across nodes by default. Snapshots and backups included.

03
Kube-OVN

SDN networking. VLAN bridging, isolated subnets, and IP pools for LoadBalancer services. No NSX required.

04
Rancher Prime

Single pane of glass for the Harvester cluster and all guest Kubernetes clusters running on top of it. One login for everything.
