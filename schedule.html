5-day plan

Recording & delivery schedule

From zero to published demos in five working days. Audience: Sales Engineers and prospects.

Day 1

Setup + Labs 1 and 2

Configure Storylane account and create the six demo shells. Verify the Harvester cluster is accessible and all six lab flows work manually. Record Lab 1 (UI Orientation) and Lab 2 (Create First VM). Add tooltips, review both recordings.

Lab 01 — UI Orientation Lab 02 — First VM
Day 2

Labs 3 and 4

Record Lab 3 (VM Networking) across three flows: create a VLAN VM network, create an IP pool, attach the network to a VM. Record Lab 4 (Storage + Snapshots) across two flows: custom storage class, snapshot and restore. Add tooltips and review both.

Lab 03 — VM Networking (3 flows) Lab 04 — Storage + Snapshots (2 flows)
Day 3

Labs 5 and 6

Record Lab 5 (Live Migration) — single short flow, keep it tight. Record Lab 6 (Rancher + K3s) across three flows: create cloud credential, provision K3s cluster, access and deploy workload. Cut to end state on the provisioning wait. Add tooltips and review all Lab 6 flows.

Lab 05 — Live Migration Lab 06 — Rancher + K3s (3 flows)
Day 4

Polish, publish, and build site

Full review pass on all six demos. Add chapter markers so viewers can jump to specific steps. Verify all tooltips match the 0-to-Hero guide text. Publish all demos in Storylane. Update the "Coming soon" buttons in this site with the live Storylane links. Review site on desktop and mobile.

All demos — polish + chapter markers Storylane — publish all Site — insert links
Day 5

Review + final delivery

SE review pass — test all six demo links, walk through the site as a prospect would. Update the PPTX deck with the same Storylane links. Final QA. Share site URL, PPTX, and demo links with the team.

SE review pass PPTX — insert Storylane links Final delivery
