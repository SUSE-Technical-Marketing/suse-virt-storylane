5-day plan

Recording & delivery schedule

From zero to published demos in five working days. Validated on SUSE Virtualization v1.7.1 with Rancher Prime v2.13.1. Audience: Sales Engineers and prospects.

Day 1

Setup + Labs 1 and 2

Configure Storylane account and create the six demo shells. Verify the Harvester cluster is accessible and all six lab flows work manually. Record Lab 1 (UI Orientation) and Lab 2 (Create First VM). Add tooltips, review both recordings.

Lab 01 — UI Orientation Lab 02 — First VM
Day 2

Labs 3 and 4

Record Lab 3 (VM Networking) across three flows: create a cluster network, create a VLAN VM network (L2VlanNetwork via Multus), attach the network to a VM. Record Lab 4 (Storage + Snapshots) across two flows: custom storage class, snapshot and restore. Add tooltips and review both.

Lab 03 — VM Networking (3 flows) Lab 04 — Storage + Snapshots (2 flows)
Day 3

Labs 5 and 6

Record Lab 5 (Live Migration) — requires 3-node cluster. Single short flow, keep it tight; show the target node selector before and after. Record Lab 6 (Rancher + RKE2) across three flows: import Harvester into Rancher, create cloud credential + provision RKE2 cluster via Harvester node driver, deploy workload and verify LoadBalancer IP. Cut to end state on provisioning waits. Add tooltips and review all Lab 6 flows.

Lab 05 — Live Migration Lab 06 — Rancher + RKE2 (3 flows)
Day 4

Polish, publish, and build site

Full review pass on all six demos. Add chapter markers so viewers can jump to specific steps. Verify all tooltips match the 0-to-Hero guide text. Publish all demos in Storylane. Update the "Coming soon" buttons in this site with the live Storylane links. Review site on desktop and mobile.

All demos — polish + chapter markers Storylane — publish all Site — insert links
Day 5

Review + final delivery

SE review pass — test all six demo links, walk through the site as a prospect would. Update the PPTX deck with the same Storylane links. Final QA against the POC guide verification checklist. Share site URL, PPTX, and demo links with the team.

Full POC reference

40-item POC verification checklist

From the official SUSE Virtualization POC Guide v1.7.1. Use this during the Day 5 SE review pass to confirm the platform meets all customer requirements before sign-off.

Deployment
  • 01Installing Harvester from ISO
  • 02Adding additional nodes to the cluster
Network configuration
  • 03Configuring HTTP proxy
  • 04Network card interface binding for management
  • 05Allocate a dedicated storage network
  • 06Create a VLAN network for VM traffic
  • 07Verify VLAN configuration across all nodes
Storage
  • 08Deploy Harvester with built-in Prometheus + Grafana monitoring
  • 09Verify Longhorn services enabled and disk configuration
  • 10Verify Longhorn data store mounted on each host
  • 14Configure backup target to S3 or NFS
  • 15Create a data volume and set up 3 replicas
VM operations
  • 11Upload an ISO or qcow2 image
  • 12Configure cloud-config user data initialization script
  • 13Import SSH key and access VM (Linux)
  • 16Create a VM with multiple NICs
  • 17Create VM with cloud-config network data
  • 18Verify GuestOS creation — Windows and Linux versions
  • 19Import VMs from VMware / vSphere to Harvester
  • 20VM snapshot and snapshot space management
  • 21Verify VM resource scalability (CPU, memory, disk)
  • 22Add, remove, and enlarge VM storage volumes
  • 23FIO Longhorn disk performance testing in a VM
  • 24CPU pinning quota lock for VM
  • 25Perform live migration of a running VM
Backup + restore
  • 26VM backup to S3 / MinIO
  • 27Restore a VM from an S3 backup
Integration + security
  • 28Support container workloads alongside VMs
  • 29Deploy Rancher Prime to manage the Harvester cluster
  • 30AD / LDAP authentication and lockout policy via Rancher
  • 31Multi-cluster management with Rancher
  • 32Node maintenance — define VM behavior during drain
DR failover + failback
  • 33Network failover — access port (add, remove, fail)
  • 34Network failover — trunk port (add, remove, fail)
  • 35Node shutdown / power-off to trigger VM failover
  • 36Power-on node and monitor Longhorn PV replication rebuild
  • 37Execute node failover with failback
  • 38Execute node failover without failback
  • 39Network packet and session analysis during failover
  • 40VM failover during network failure

SUSE recommends a 3-week POC cycle to cover all 40 items. Reference: SUSE Virtualization POC Guide v1.7.1
